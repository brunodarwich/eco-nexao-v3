# Prompt — ECO-2510: fotos Google por proxy

```text
/goal Entregar fotos Google temporárias, atribuídas e resilientes sem copiar binários para o Storage.

Execute somente ECO-2510 após ECO-2508/ECO-2509. Use a cadeia L completa. /browser:
revalide política oficial de Place Photos, autoria, googleMapsUri, flagContentUri,
expiração e exibição em mapa/plataforma aprovada.

Use o modelo google_proxy existente: resource name, dimensões, autorizações,
atribuições, validade e URL temporária resolvida pelo backend. Storage guarda apenas
mídia editorial própria. Implemente fallback sem foto, expiração, remoção e erro
seguro; nunca use URL Google como mídia permanente.

Testes usam fixtures e mock HTTP; nenhum download real/CI. Verifique atribuição
visível e acessível. Não inicie ECO-2511.
```
