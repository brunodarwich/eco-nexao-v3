# Prompt — ECO-2310: Minha localização

```text
Execute somente ECO-2310 — opção `Minha localização` em primeiro plano.

Você é coordenador. Obedeça docs/mapa_dinamico/protocolo_sessoes.md e crie em
sequência: planejador → implementador → testador → revisor → consolidador. Nenhum
subagente cria outro; findings voltam ao implementador.

Dependência: ECO-2309 comprovada e ADR 0012 aceito.

Objetivo observável:
Instalar a versão de expo-location compatível com Expo SDK 54 pelo comando oficial,
configurar somente permissão foreground e permitir que o usuário confirme sua posição
antes de pedir o preview fake. Coordenada vive apenas em memória.

Leia AGENTS, ADR 0001/0012, Expo Location SDK 54 atual, app.json, package/lockfile,
OriginSelector, tela route/map, hooks/client e padrões de acessibilidade.

Escopo:
- dependência/config plugin e mensagens de permissão necessárias;
- hook/serviço frontend para status, permissão e posição atual;
- opção Minha localização e confirmação explícita;
- pin temporário de origem apenas se o contrato do adapter já suportar sem ampliar para
  toque manual;
- estados concedida, negada, serviços desligados, timeout, imprecisa e retry;
- mocks Jest e testes de componente.

Proibido:
- background location, geofencing ou rastreamento contínuo;
- armazenar coordenada em AsyncStorage, Supabase, URL, log ou analytics;
- implementar toque/arraste no mapa (ECO-2311);
- fornecedor real ou chamada externa em teste.

Aceite:
- permissão só é pedida após ação do usuário;
- negação oferece Escolher no mapa/origens fixas sem loop de prompt;
- preview só ocorre após confirmação;
- fechar/sair descarta estado conforme ADR;
- install compatível, lockfile, typecheck, Jest, OpenAPI e configuração Expo verificados;
- sem device físico, status é `PARTIAL`, não VERIFIED móvel.

Não inicie ECO-2311.
```
