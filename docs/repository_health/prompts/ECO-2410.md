# Prompt — ECO-2410: auditoria final e handoff

```text
/goal Confirmar independentemente a saúde do repositório e entregar um processo sustentável de manutenção.

Execute somente ECO-2410 quando todas as tasks aplicáveis tiverem evidência. Esta é uma
auditoria, não uma oportunidade de refactor. Leia toda a série ECO-24XX, project_status,
Git diff/history, CI, deploy configs e documentação ativa. Orquestre arquiteto de auditoria
-> implementador apenas para correções documentais mínimas -> verificador independente.

Reproduza o health check completo, testes backend/frontend aplicáveis, OpenAPI, migrations,
links, secret scan, builds e smokes autorizados. Compare o repositório ao inventário ECO-2401
e explique cada remoção, arquivo novo e pendência. Amostre documentos arquivados e evidências
para provar recuperabilidade. Não acessar production nem promover conteúdo.

Produza relatório final com métricas antes/depois, decisões, comandos/exit codes, falsos
positivos conhecidos, manutenção mensal e backlog residual. VERIFIED exige confirmação do
verificador; mobile/staging/remotos indisponíveis permanecem PARTIAL/NOT_VERIFIABLE.

Aceite: fonte de status única, histórico localizável, working tree sem ruído gerado,
arquitetura protegida e rollback documentado. Não declare o produto pronto para produção
nem inicie outra iniciativa. Entregue handoff ao owner.
```
