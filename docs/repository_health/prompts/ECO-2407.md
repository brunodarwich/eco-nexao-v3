# Prompt — ECO-2407: governança de assets

```text
/goal Definir origem canônica e sincronização verificável para assets duplicados sem quebrar builds independentes.

Execute somente ECO-2407. Leia configs Expo, landing page, design specs, licenças/créditos
e todas as referências de assets. Orquestre arquiteto -> implementador -> verificador.
O arquiteto produz grupos por hash e consumidores; nenhuma imagem é removida só por ter
hash duplicado.

Escolha a solução mínima: manifesto de origem/cópias ou script determinístico de sync.
Não introduza symlinks sem provar compatibilidade Windows, Git, Expo, Vercel e Netlify.
Preserve nomes públicos e créditos. Não recomprima imagens nem altere aparência nesta task.

Aceite: manifesto/checksum detecta drift; app, landing e docs continuam resolvendo todos
os assets; builds aplicáveis passam; verificador compara hashes e procura referências
quebradas. Mudança que acople deploys antes independentes exige decisão do owner. Não
inicie ECO-2408.
```
