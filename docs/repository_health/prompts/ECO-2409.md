# Prompt — ECO-2409: testes de fronteiras arquiteturais

```text
/goal Impedir automaticamente o retorno de acoplamentos e fallbacks que degradam a arquitetura.

Execute somente ECO-2409. Leia spec, ADRs, OpenAPI, runtimeArchitecture.test.ts e camadas
backend/frontend. Orquestre arquiteto -> implementador -> verificador. Não refatore produto;
adicione guardas pequenas, determinísticas e com baixo falso positivo.

Proteja no mínimo: componentes não acessam Supabase territorial; AppContext não acumula
listas remotas; routers FastAPI não fazem SQL direto; mocks/fakes não são fallback de
production; frontend usa tipos/cliente de contrato; migrations individuais são fonte do
schema; provider revogado não pode ser selecionado em runtime. Documente exceções legítimas.

Aceite: verificador prova que cada teste falha com uma violação temporária controlada e passa
no código real; suítes completas proporcionais ficam verdes; nenhuma regra depende de path
frágil sem justificativa. Não inicie ECO-2410.
```
