# Prompt — ECO-2408: check automático de saúde

```text
/goal Criar um comando único, rápido e confiável que detecte regressões de higiene antes do merge.

Execute somente ECO-2408 depois das políticas anteriores. Leia AGENTS, DEVELOPMENT,
scripts e workflows. Orquestre arquiteto -> implementador -> verificador. Reuse ferramentas
já instaladas e scripts existentes; não adicione dependência sem justificar custo, lockfile
e manutenção.

Implemente um health check componível para Git/status esperado, segredos, arquivos grandes,
artefatos proibidos, links documentais, OpenAPI drift, imports/configs revogados, migrations
e checks de lint/type/test existentes. Separe modo rápido local de modo completo CI. Mensagens
devem indicar correção, nunca imprimir conteúdo sensível. Evite lógica destrutiva.

Aceite: comando retorna 0 no baseline aprovado; uma fixture temporária segura demonstra que
cada regra crítica falha com mensagem útil; CI aplicável o executa sem acessar rede/production;
verificador reproduz sucesso e falhas controladas e confirma tempo razoável. Não inicie ECO-2409.
```
