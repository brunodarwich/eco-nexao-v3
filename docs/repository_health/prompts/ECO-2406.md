# Prompt — ECO-2406: configuração de deploy e wrappers

```text
/goal Eliminar ambiguidade de entrypoints e deploy mantendo Render, Vercel e desenvolvimento funcionais.

Execute somente ECO-2406 após a matriz ECO-2402 aprovada. Leia ADR 0005, DEVELOPMENT,
render.yaml, ambos vercel.json, root/backend main e requirements, workflows e comandos
reais. Consulte documentação oficial atual apenas para validar sintaxe instável.
Orquestre arquiteto -> implementador -> verificador.

Mapeie quem executa cada configuração e de qual working directory. Escolha uma origem
canônica por deploy somente quando a evidência for suficiente; não alterar provedor,
plano, região, domínio, segredo ou production. Remova wrappers da raiz apenas se CI,
Vercel, Render e ferramentas locais não os consumirem. Atualize DEVELOPMENT e índices.

Aceite: exatamente um caminho documentado para backend e frontend; builds/smokes locais
aplicáveis passam; configs não divergem; verificador executa comandos a partir dos mesmos
diretórios usados pelas plataformas. Qualquer dependência externa não verificável resulta
em PARTIAL, não suposição. Não inicie ECO-2407.
```
