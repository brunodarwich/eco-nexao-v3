# Prompt — ECO-2402: fonte única de status

```text
/goal Criar uma fonte única, verificável e atual para o estado do produto e o trabalho aberto.

Execute somente ECO-2402 após ECO-2401. Leia as fontes normativas e todo o pacote
repository_health. Orquestre arquiteto -> implementador -> verificador conforme o
protocolo. O arquiteto cruza ADRs, spec, OpenAPI, tasks, evidências, Git e código; o
verificador confirma cada alegação material em fonte primária local.

Produza docs/project_status.md e um backlog que contenha somente trabalho realmente
aberto. Não reescreva ADRs, não declare mobile/staging/production verificado por mocks
e não transforme artefato declarativo em prova de execução. Marque divergências como
UNKNOWN/PARTIAL até evidência reproduzível.

Crie também uma matriz documental: caminho, owner, status ACTIVE/COMPLETED/SUPERSEDED/
ARCHIVED, substituto, ação proposta e justificativa. Esta task propõe manter/arquivar/
remover, mas não move nem apaga material. Pare para decisão do owner se a classificação
mudar a fonte normativa ou descartar evidência.

Aceite: um leitor identifica em menos de uma página o que funciona, o que falta, a
próxima task autorizada e os gates humanos; não existem dois backlogs chamados ativos;
links são válidos; verificador lista contradições resolvidas e as ainda abertas. Não
inicie ECO-2403.
```
